export function dialSamples(samples: TrajectorySample[], targetRangeM: number): TrajectorySample[]
  The same shot after the shooter dials elevation and windage so the bullet hits the point of aim at targetRangeM. This is a small rotation of the whole path about the muzzle, not new physics.
  t = sampleAt(samples, targetRangeM). If t is null or targetRangeM <= 0, return a copy of samples unchanged.
  For every sample s return { ...s, pathM: s.pathM - t.pathM * (s.rangeM / targetRangeM), windageM: s.windageM - t.windageM * (s.rangeM / targetRangeM) }. Leave every other field as it is.

Change cameraPose 'top': up is now (0, 0, -1) (downrange runs left to right across the screen, like the side view). Position and target stay the same.
